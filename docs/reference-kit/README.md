# tolpagorni thoughts website kit

This kit holds everything a developer needs to build the new tolpagorni.com with Claude Code.

## What's inside

| Path | What it is |
|---|---|
| `CLAUDE.md` | Instructions Claude Code reads automatically: rules, reading order, structure |
| `docs/01-brief.md` | The website concept and structure brief, v0.7 |
| `docs/02-decisions.md` | Decisions made while designing, plus open questions |
| `docs/03-content-model.md` | Proposed CMS content types and relationships |
| `docs/04-design-system.md` | Colours, type, motion, components, accessibility |
| `docs/05-build-plan.md` | Recommended stack, milestones, acceptance criteria |
| `design/mockup-pages/` | Inspirational mockup v0.8: eight linked example pages. Open `index.html` in a browser, and `guide.html` for how to read it. Shared online at https://claude.ai/artifact/JmtxeLnu9ftzDMTUGcuMDR |
| `design/homepage-mockup.html` | The earlier single-page homepage mockup (v0.7) |
| `design/concept-history-v0.6.html` | The earlier concept page with inspiration sites, for background |
| `assets/brand/` | Mountain line art (SVG), emblem (SVG and PNG), original logo file |
| `assets/film/` | The Norrsken northern-lights film |
| `assets/photos/` | Photos of Tolpagorni (owned by tolpagorni thoughts) |
| `reference/` | The Chemistry of Knowledge (foundation text), deck style guide, Speed Layers cover |

## How the developer starts

1. Create a new, empty Git repository and unzip this kit into it, so that `CLAUDE.md` sits at the root and the brief stays in `docs/`.
2. Open the folder in Claude Code.
3. Start with a prompt like:

   > Read CLAUDE.md and the docs in the order it lists, then open design/homepage-mockup.html. Propose the project setup for milestone M0 in docs/05-build-plan.md, list any questions for Magnus, and wait for my go-ahead before installing anything.

4. Work milestone by milestone. Each one has acceptance criteria in `docs/05-build-plan.md`.
